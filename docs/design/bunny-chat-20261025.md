# 편지 토끼 AI 질문 · 2026-10-25

사용자는 안내 문장 끝의 물음표를 눌러 행동하도록 유도하고, AI 답변이 나오는 동안 옆 토끼가 말하는 모션을 요청했다.
제공자는 사용자 선택에 따라 OpenAI로 연결한다.

## 화면과 동작

- 안내 문장 바로 뒤 44px 물음표 버튼. 후속 요청에 따라 원형 배경·테두리·후광을 제거하고 22px 물음표 글자만 보인다. 질문창이 닫혀 있을 때 1.6초 간격으로 글자가 계속 깜박이며, 열면 멈추고 닫으면 다시 시작한다.
- 같은 편지 안에 질문창이 열리고 입력으로 포커스가 이동한다. 닫기·Escape는 요청을 취소하고 물음표로 포커스를 돌린다.
- 질문은 300자 이내. 예시 문장 선택은 입력만 채우며, 물어보기 버튼을 눌러야 전송한다.
- 실제 API 답변을 2글자씩 표시하는 동안 토끼가 가볍게 움직이고 말소리 선이 나타난다. 끝나거나 창을 닫으면 모션을 멈춘다. 음성은 재생하지 않는다.
- 동작 줄이기 설정에서는 유도·말하기 애니메이션 없이 답변을 바로 표시한다. 스크린리더는 매 글자가 아닌 완료된 답변을 안내한다.
- 오류는 AI 답변으로 표시하지 않으며 입력을 보존해 다시 시도할 수 있다. 오래된 요청이 늦게 완료되어 새 대화를 덮지 않도록 구분한다.

## 실제 연결

`api/bunny-chat.ts`는 기존 정적 사이트 옆의 독립 Vercel Node.js 함수다. Next.js의 `output: export`는 유지했다.
서버 구현은 `lib/bunny-chat-server.ts`이며 OpenAI Responses API에 요청한다. 새 SDK 의존성은 없다.

- `OPENAI_API_KEY`: 서버 키. `NEXT_PUBLIC_` 접두사를 사용하지 않는다.
- `BUNNY_AI_ENABLED=true`: 사용자가 승인한 환경에서 연결 활성화.
- `OPENAI_BUNNY_MODEL`: 기본 `gpt-5.4-mini`; `reasoning.effort=none`, 출력 500토큰 제한.
- `store: false`. 현재 질문과 최근 3회 대화만 전송한다. 편지 작성기·보관함·localStorage는 접근하지 않는다.
- 모델에 브랜드·제품·미정 사항의 기존 `lib/facts.ts`를 제공한다. 모델 답변은 공식 정보나 확인된 효능으로 취급하지 않는다.
- 본문 16KB, 역할·대화 순서·메시지 길이 제한, 허용 Origin, 20초 서버 타임아웃, 25초 브라우저 타임아웃.
- 인스턴스별 10분 8회 제한과 최대 2,000개 임시 IP 버킷. 분산된 계정 전체 사용량 제한은 아니다. 공개 활성화 시 호스팅 방화벽·제공자 사용량 설정을 따로 적용해야 한다.
- 질문·답변·키·제공자 오류 원문은 애플리케이션 로그에 남기지 않는다. OpenAI의 부정 이용 방지 보관은 `store: false`와 별개다.

공식 문서: [Responses 텍스트 생성](https://developers.openai.com/api/docs/guides/text),
[GPT-5.4 mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini),
[데이터 처리](https://developers.openai.com/api/docs/guides/your-data).

## 로컬 확인

`npm.cmd run build` 후 `npm.cmd run preview`로 정적 화면과 실제 서버 핸들러를 함께 제공한다.
주소는 http://127.0.0.1:51900 이다. 기본 정적 `serve out`은 AI API를 실행하지 않는다.
서버는 `.env.local`을 시작할 때 읽으므로 값을 바꾼 뒤 재시작한다. `.env*`와 `.preview-api/`는 Git에서 제외한다.

작성 당시 로컬 API 키는 없으며, Vercel 환경 변수 조회도 팀 접근 권한(403)으로 차단되었다.
사용자가 API 키 설정은 나중에 하겠다고 답해 연결 작업을 보류했다. 이 상태에서 실제 API는 503 `not_configured`를 반환한다.
실제 OpenAI 모델 응답 검증과 운영 배포는 아직 하지 않았다. 이전 영상 작업도 정지 상태를 유지한다.

## 검증

- 13개 신규 UI·서버 테스트: 포커스, 전송 범위, 오류, 취소·재시도, 모션 종료, 서버 검증, 한도, 제공자 오류와 응답 추출.
- 전체 94개 테스트, TypeScript, 정적 빌드, 보존 검사 통과.
- 1440×1000, 390×844, 320×800에서 실제 503 안내와 입력 보존을 확인했다.
- 테스트용 HTTP 응답으로 글자 표시·말하기 모션·모션 종료·동작 줄이기·닫기 후 포커스·가로 넘침 없음 확인.
- 테스트용 응답을 실제 OpenAI 생성 결과로 취급하지 않는다. 캡처 이름에 `fixture`를 표시했다.
- 화면과 측정 기록: `outputs/dearpapa-bunny-chat-20261025/`.
- 후속 물음표 수정: `bare-question/`에 PC·390px·320px 캡처와 실제 불투명도 변화, 배경·테두리 없음, 열기 시 중지·닫기 시 재개, 동작 줄이기 검증을 기록했다. 수정 후 94개 테스트·빌드·보존 검사도 통과했다.
