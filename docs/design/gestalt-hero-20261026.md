# 첫 화면 게슈탈트 개선 적용

2026-10-26 사용자가 전후 비교 시안의 적용을 요청했습니다.

## 적용

- 상품 종류·이름, 기존 슬로건·설명·출시 상태와 행동 버튼을 한 묶음으로 배치했습니다. 모바일에서도 설명이 사진과 상담보다 먼저 나옵니다.
- `제품 알아보기`를 채운 주 버튼으로, `한 줄 편지 써보기`를 같은 높이·서체의 테두리 버튼으로 변경했습니다.
- 제품 사진과 캡션을 하나의 figure로 두고, Sodam 편지·상담 카드를 별도 영역으로 옮겼습니다. 카드 그림자는 제거했습니다.
- HeroLetterPreview가 두 영역의 상태를 함께 관리합니다. 사진 속 문구·Sodam 서명·편지 입력·한 줄 기본 답변·질문창·모션은 기존 로직을 사용합니다.
- 정적 안내는 서버 컴포넌트에서 children으로 전달합니다. 상품/편지 링크는 기존 `/#product`, `/#letter`와 편지 작성기의 초점·분석 이벤트를 유지합니다. 검토용 HTML의 기능 제한 안내는 실제 화면에 넣지 않았습니다.

## 참고한 실제 화면

- [Glossier](https://mobbin.com/sites/sections/a53f80e9-e6b1-407d-b7b9-ecf565f96e30): 상품별 동작에 동일한 버튼 규칙 적용.
- [Dollar Shave Club](https://mobbin.com/sites/sections/4f895f9d-289a-4158-8042-95e9f6ff55f3): 사진과 설명의 묶음, 진한 주 CTA, 작은 상담 진입점.

배치와 문구의 구체적인 선택은 Dear Papa에 맞춘 제안입니다. 레퍼런스가 전환 효과를 입증하는 것은 아닙니다.

## 검증

- `npm.cmd run build`: 테스트 17개 파일의 136개 항목, TypeScript, 정적 빌드 및 보존 검사 통과.
- `npm.cmd run typecheck`, `git diff --check`: 통과.
- 브라우저: PC 1440×1000, 모바일 390×844 화면 확인. 390px 및 320px 폭에서 문서 가로 넘침 없음.
- 편지 입력을 바꾸면 사진 속 문구와 접근성 이름에 반영되는 것 확인.
- 잠시 멈춘 뒤 `Sodam의 기본 답변` 표시 확인. Gemini 호출과 구분됨.
- 질문창 열기 시 입력 초점, 닫기 시 질문 버튼 초점 복귀 확인.
- 편지 CTA는 기존 작성기로 이동해 `편지 내용` 입력에 초점. 제품 CTA는 제품 영역으로 이동.
- 기존 블루 자산, 공식 문장·제품 사실·메타·JSON-LD·루트 파일 보존.

로컬 API 키는 미설정 상태이며 실제 Gemini 응답은 이번 검증 범위에 포함하지 않았습니다. 가격·출시일·결제 미연결 상태를 유지하며 구매 CTA를 만들지 않았습니다. 3초 이해 및 전환 효과는 사용자 테스트가 필요합니다.
