# Skill 05: 성과 관리·변주 (잠김 — 유료 개시 승인 전 실행 금지)

## 상태
**잠김.** DEAR PAPA는 출시 준비 중이고 결제·주문이 연결되지 않았다. 광고비를 쓰는 모든 작업은 사용자가 유료 개시를 별도로 승인하기 전까지 하지 않는다. 이 문서는 그때 쓸 규칙을 미리 정해 둔 것이며, 저장소에 Meta Ads API 코드는 없다.

## 잠금 해제 조건 (모두 필요)
1. 사용자가 이 스레드나 프로젝트 채팅에서 유료 집행 개시를 직접 승인
2. 출시일·가격·판매 채널 확정, 주장 상태표 갱신(효능 증빙 등)
3. 일 예산 상한과 계정 총 예산 상한을 사용자가 숫자로 지정
4. Meta Ads API 권한(광고 계정 ID, 토큰)을 사용자가 `.env`에 등록

## 잠금 해제 후 규칙 (보고서 3단계를 이 브랜드에 맞게 바꾼 것)
### 모니터링·브리핑
- 매일 아침 Insights API로 소재별 지출, 노출, CPM, CPC, 클릭률, 3초 시청률, 전환을 읽어 `outputs/performance_report.json`에 쌓는다(읽기 전용).
- 사용자에게 5줄 브리핑: 지출 합계, 상위·하위 3개 소재, 예산 소진율.

### 성과 미달 소재
- 기준(예: 소재당 지출 1만 원 이상 + CPC가 계정 중앙값의 1.5배 초과)은 사용자가 정한다.
- 미달 소재는 **일시정지만 제안**한다. 삭제하지 않는다(학습 데이터·심의 기록 보존).
- 일시정지 실행도 처음에는 사람 확인 후. 사용자가 자동 일시정지를 명시적으로 허용한 경우에만 자동화한다.

### 신규 소재 투입
- 새 소재는 Skill 04의 샘플 컨펌·게시 승인을 통과한 것만 쓴다.
- 활성 소재 수 상한(보고서 150개)은 사용자가 정한 숫자를 따른다. 예산 상한을 넘는 투입은 하지 않는다.

### 베스트 소재 변주
- 상위 소재의 `variationAxes`(후킹 문구, 첫 장면, 문장 순서, BGM) 중 한 축만 바꿔 새 기획서를 만든다.
- 변주 기획서도 02 승인부터 다시 거친다.

## 하지 않는 것
- 사람 승인 없는 예산 증액·캠페인 생성·활성화
- 소재 삭제
- API 오류 시 우회 경로로 재호출 (보고서의 "우회 API 호출"은 적용하지 않음) — 오류는 기록하고 사용자에게 알린다.
