# Sodam 3D dance r1

> Superseded for delivery by [performance r2](sodam-performance-r2.md): same frames, beats and shadow, cut again with a clean outline at 384 px.

The homepage letter companion uses a transparent, silent 3D-style animation at
149 BPM. One sixteen-beat loop is 6,443 ms. The character's joint motion is in
the asset; CSS does not translate, rotate or squash the whole cutout.

## Source and edit

- Generated once with Sunra Kling 4.0; the user approved 165 credits.
- Task: `3d68807a-7a2e-4cc6-bbc7-0026c22a0ce8`.
- Original: 1440 × 1440, 24 fps, 7.041667 seconds, preserved in the local
  `Sodam-v2-Continue-at-Home/exports/Sodam-3D-dance-r1/source/` delivery.
- Early traveling steps showed foot sliding and were excluded. Source frames
  109–115 (zero-based) supply the grounded knee/upper-body groove.
- A forward/reverse two-beat phrase, with endpoint holds, repeats eight times.
  The last and first poses match. No crossfade creates duplicated limbs.
- Black background removed, matte edge contracted and feathered, then resized
  to 256 × 256. A soft contact shadow anchors the feet.
- This is a visually reviewed rendered animation, not a rigid-body simulation
  or a rigged 3D model. The original song audio is not included.

## Playback

The static poster matches the start/end pose. Animation stops during writing
or conversation, when outside the viewport, in a hidden tab, or when reduced
motion is requested. A separate pause button preserves the visitor's choice
across writing sessions. If the animated file fails, the static poster remains.

The existing letter action, advice, product copy, structured data and original
image assets are preserved. Asset metadata, contact-sheet review and source
hash are stored in the local delivery's `review/verification-r1.json`.
